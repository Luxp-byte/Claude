# Freelancer Invoice & Expense Kit

A sellable digital product: an offline, single-file invoice and expense tracker for freelancers. It needs no server, no account and no dependencies.

| Path | What it is |
|---|---|
| `product/invoice-kit.html` | **The product.** Open it in any browser. Data stays in the browser (localStorage). |
| `product/QUICK-START.txt` | Buyer instructions (ship this in the zip) |
| `product/LICENSE.txt` | Buyer license (ship this in the zip) |
| `landing/` | Sales page plus screenshots. Host it free on GitHub Pages, Netlify or Cloudflare Pages |
| `LAUNCH-PLAN.md` | Pricing, platforms, fees, marketing and the copyright note |

## Features
Invoices with line items, discount, tax/VAT/GST, logo and any currency · print/save as PDF · draft/sent/paid status with automatic overdue detection · clients · expense log by category · CSV export · JSON backup/restore · sample data · light/dark mode · mobile-friendly.

## Build the zip to sell
```bash
cd product && zip ../invoice-kit-v1.0.zip invoice-kit.html QUICK-START.txt LICENSE.txt
```
Replace the `YEAR`, `YOUR NAME`, `YOUR_EMAIL` and `BUY_LINK` placeholders first.
